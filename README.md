# WAVEROOM — Recording & Podcast Studio

**Готовый учебный проект по ICT6001, Week 9 (26 October 2026).**

Адаптивный сайт вымышленной студии звукозаписи. Он полностью состоит из HTML, CSS и JavaScript и подходит для бесплатного хостинга через GitHub Pages. В папке `figma/` находятся скриншоты реальных страниц в четырёх сочетаниях размеров/тем и SVG-макеты для импорта в Figma.

## Как открыть сайт

1. Распакуй ZIP, **не вынимая файлы из папок**.
2. Открой `index.html` двойным щелчком или запусти проект через расширение VS Code **Live Server**.
3. Для проверки мобильной версии открой в Chrome `F12` → режим устройства (Ctrl+Shift+M) → укажи 390 × 844. Проверяй также ширину 320 и 480.
4. Переключи тему значком луны/солнца вверху или в подвале.
5. Заполни форму и нажми **Confirm Demo Booking**; результат сохранится в `localStorage` этого браузера. Можно отменить запись или скачать файл события `.ics` для календаря.

### Что сделано

- Семантические `header`, `nav`, `main`, `section`, `article`, `footer`.
- 5 обязательных компонентов: шапка с бургер-меню, Hero, Grid с карточками, форма и Footer.
- Дополнительные разделы Equipment, Prices, Our Works с тремя оригинальными синтетическими аудиодемонстрациями.
- Mobile-first CSS Grid/Flexbox, `@media (min-width: 1024px)`, относительные единицы для ширины/отступов блоков, отсутствие горизонтального скролла на 320–480.
- Темная тема по умолчанию, ручное переключение на светлую, сохранение выбора.
- HTML5-проверка (`required`, `type="email"`, `type="tel"`, `pattern`, `minlength`) + CSS `:user-invalid`, `:user-valid`, фокус и валидация на стороне JavaScript.
- Демонстрационное бронирование: дата, время, длительность, звукорежиссёр, имя, телефон, email; расчёт цены, проверка конфликтующих слотов, локальное сохранение, отмена брони, `.ics`.
- Фотография-заставка WebP, векторный логотип SVG, оригинальные WAV-примеры.
- не менее 3 оформленных коммитов в Git (папка `.git` включена в архив).

> **Важно: демонстрация, а не действующий сервис записи.** GitHub Pages — статический хостинг. Брони хранятся только в браузере посетителя и не синхронизируются между пользователями; ни email, ни телефон не отправляются менеджеру. Чтобы принимать *реальные* онлайн-заявки, понадобится бэкенд / внешняя форма с серверным хранением. Пока эта интеграция отсутствует — не называй бронирование реальным. Цены, оборудование и студия — учебные примеры.

## Что требуется лично выполнить в Figma и GitHub

**Figma:** импортируй SVG-макеты как исходные редактируемые векторные композиции и создай четыре Figma Frame размером 1440 и 390 с Layout Grid (12/4 колонки). Точные скриншоты PNG предназначены для сверки с готовым сайтом. Это не нативный `.fig` документ; **нативные фреймы, Figma Layout Grids и проверку WCAG в интерфейсе Figma нужно добавить самостоятельно**. В `docs/FIGMA_GUIDE_RU.md` описана последовательность.

**GitHub:** архив содержит локальный репозиторий и несколько коммитов, но для сдачи его нужно запушить в **свой публичный** репозиторий и включить Pages. Без входа в твой аккаунт сайт не может быть опубликован автоматически. Смотри `docs/GITHUB_GUIDE_RU.md`.

**Перед публикацией:** измени демонстрационный номер `+7 (700) 000-00-00` и ссылки на главные страницы Spotify, YouTube, Instagram на настоящие данные **только если они у тебя есть**. Сейчас это примеры, а не контакты настоящей компании.

## Быстрая проверка в VS Code

Встроенный терминал: `python -m http.server 8000`, затем в браузере `http://localhost:8000`. Python не нужен на GitHub Pages.
