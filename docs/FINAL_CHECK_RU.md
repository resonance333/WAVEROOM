# LAB 9 — статус и чек-лист сдачи

## Реализовано в коде

- Header/Nav, Hero, Grid Services, Booking form, Footer и дополнительные разделы.
- Графика: `images/studio.webp`, `images/logo.svg`; локальные аудиофайлы `assets/*.wav`.
- Mobile-first CSS Grid/Flexbox, media query **1024px**, относительные единицы.
- Смена тем, мобильное меню, демонстрационная бронь с HTML5 validation и локальным хранилищем.
- Семантический HTML без `div`; SVG/WebP; доступные подписи; улучшенный контраст и прогрессивная CSS squircle.
- История Git-коммитов.

## Проверки Chromium (встроенная копия HTML+CSS+JavaScript)

- Ширины 320, 390, 480, 1024, 1440: без горизонтальной прокрутки.
- Услуги: 1 колонка на телефоне и 3 на 1024px.
- Меню: открытие/закрытие; темы: переключение.
- Тестовая бронь: Track Mixing, 2 часа, инженер → 32 000 ₸; форма успешно создаёт локальную запись.
- Ошибок JavaScript во время этих проверок не было.
- Ограничение проверки: тестовый браузер в контейнере блокировал переходы на локальные URL. Публичный сайт через GitHub Pages пока НЕ проверен.

## Осталось у владельца аккаунтов

1. Figma: создать полноценный Design File с четырьмя Frame шириной 1440/390 и нативными Layout Guides (12/4). Векторные SVG уже включены. Проверить композицию и контраст плагином Figma.
2. GitHub: создать Public repository, отправить локальную историю Git и включить Pages с ветки `main` и папки `/ (root)`.
3. Проверить опубликованный сайт по внешней ссылке и совпадение с Figma.
4. На защите продемонстрировать мобильный режим, переключатель тем, работу формы, код и `git log --oneline`.

Демонстрационная бронь сохраняется **только в браузере**: это не настоящий многопользовательский сервис. Телефон и ссылки на соцсети — заглушки.
