# Быстрая подготовка к защите (15 баллов)

**1. Что такое Mobile-First?** Сначала пишем стили для маленького экрана. На экранах от 1024px `@media (min-width: 1024px)` изменяет сетку карточек с одной колонки на три и показывает обычное меню вместо бургер-меню.

**2. Что такое CSS Grid?** Система размещения элементов по строкам и колонкам. У услуг `.service-grid` используется `display:grid`; на широком экране `grid-template-columns:repeat(3,minmax(0,1fr))`.

**3. Что такое Flexbox?** Инструмент для распределения элементов по одной оси. Здесь используется для навигации, кнопок, шапок карточек и ряда полей.

**4. Почему нужны rem/% вместо px?** Они зависят от размера шрифта/контейнера, поэтому сайт лучше адаптируется. Значения `px` в `@media` — это условия переключения, как требует задание, а не ширины блоков.

**5. Зачем HTML5-семантика?** `header`, `nav`, `main`, `section`, `article`, `footer` помогают браузерам и вспомогательным технологиям понимать структуру сайта.

**6. Что такое `required` и `type="email"`?** Браузер проверяет обязательность и базовый формат вводимых данных. В CSS применяется визуальное выделение `:user-valid`/`:user-invalid`. В JS дополнительно проверяется время и отсутствие пересечений в локальных записях.

**7. Как работает бургер-меню?** Кнопка переключает свойство `hidden` блока навигации и `aria-expanded`. На широком экране видно обычное меню.

**8. Как работает переключение темы?** JS меняет `data-theme` на элементе `html`; CSS использует набор цветовых переменных для Dark и Light. Выбор хранится в `localStorage`.

**9. Зачем Git?** Он фиксирует изменения в истории коммитов. Здесь три локальных коммита: базовый HTML, адаптивные стили, интерактивность и вспомогательные ресурсы.

**10. Что такое GitHub Pages?** Бесплатная публикация статических HTML/CSS/JS-проектов прямо из GitHub-репозитория.

**11. Это действительно бронирует студию?** Нет. Это полнофункциональная демонстрация на стороне клиента: проверяет поля, время, хранит локальные записи, рассчитывает цену, помогает отменить бронь и экспортировать событие календаря. Для реального многопользовательского бронирования нужен бэкенд — на статическом GitHub Pages без API он отсутствует.

**12. Как проверить, что сайт адаптивен?** В DevTools выбери ширину 320/390/480/1024/1440, проверь отсутствие горизонтального скролла, перестройку Grid, бургер, CTA и форму.

**Краткое представление на английском:**

> My project is WAVEROOM, a responsive website for a recording and podcast studio. I designed a dark and a light theme, a mobile-first layout, service cards, equipment and pricing sections, and a demo booking form with HTML validation. The page uses semantic HTML, CSS Grid, Flexbox, and a media query at 1024 pixels. I can show my version history on GitHub and publish the static project using GitHub Pages. Reservations in this demo are stored locally in the browser.
