# Figma: как подготовить сдачу по критериям (25 баллов)

Файлы SVG — импортируемые векторные композиции, а PNG — **точные скриншоты работающего сайта**, полученные в браузере. Они не заменяют нативный документ Figma.

1. Зайди на figma.com, создай **New design file**, назови `WAVEROOM / ICT6001`.
2. Нажми **F**, создай четыре нативных Frame: два Desktop с **W = 1440**, два Mobile с **W = 390**. Высоту увеличь до полной высоты сайта (референсы: около 6847 для desktop и 9451 для mobile; изменяй при необходимости).
3. Назови фреймы `Desktop / Dark`, `Desktop / Light`, `Mobile / Dark`, `Mobile / Light`.
4. Импортируй соответствующие SVG из `figma/vector_*.svg` в документ (перетащи файл на холст). Помести их внутрь соответствующих Frame. Это векторные стартовые макеты; **цвета и текст можно доработать в Figma**. Изображение Hero внутри SVG встроено в растровом формате и редактируется как картинка.
5. Для строгого пиксельного соответствия помести на отдельный слой или страницу скриншот `figma/desktop_dark.png` и аналогично другие. Эти изображения точно соответствуют HTML/CSS на момент генерации и подходят для визуального сравнения.
6. В правой панели Figma выбери каждый Desktop Frame → **Layout grid / Layout guide** → Columns → **12** колонок. Рекомендуемая конфигурация: margin 96, gutter 24.
7. Для Mobile Frame → Columns → **4** колонки. Рекомендуемая конфигурация: margin 24, gutter 16.
8. Проверь, что мобильные CTA доступны в нижней или средней области экрана, а меню свёрнуто в ☰. Минимальная высота интерактивных кнопок — около 44 px.
9. Создай/настрой **Dark и Light темы**. В исходном сайте они уже реализованы; в Figma ориентируйся на PNG обоих вариантов.
10. Проверь контраст текста, особенно мелких подписей. Для WCAG AA ориентир — **4.5:1** для обычного текста и **3:1** для крупного. При необходимости увеличь контраст в макете и CSS одновременно.
11. Проверь, что `logo.svg` импортируется как вектор. Для экспортируемых иконок поставь SVG; для фото — WebP. Выдели нужные элементы и в панели Export сделай соответствующий формат.
12. Сверь готовые фреймы и открытый сайт. Преподаватель даёт **5 баллов за совпадение** при защите.

**Честное ограничение:** приложенные SVG и PNG не являются нативными `.fig` файлами, а HTML-скриншоты не содержат редактируемых фреймов и Layout Grids. После импорта нужно создать и настроить нативные Frame и колонки вручную.
